Privacy Policy

Last updated: 19 October 2026

This policy describes how the personal applications operated by Kayan Marcolini on this domain handle data. These are private personal projects and are not offered to the public.

Who operates these applications

Kayan Marcolini, an individual based in Sunshine Coast, Queensland, Australia. Contact: kayanmarcolini@gmail.com

What data is accessed

The applications access data from the operator's own Google account, with explicit authorisation through Google OAuth:

  • Google Sheets: reading and writing specific spreadsheets created by the operator, used as the data store for the automations.
  • Gmail: reading and sending messages in the operator's own account, where an automation requires email notification.

How the data is used

Solely to carry out the function the operator has configured — for example, reading a spreadsheet, processing the data and sending a notification. No data is used for advertising, profiling or any secondary purpose.

Sharing

No data is sold, rented or shared with third parties. Data moves only between Google's APIs and the operator's private n8n instance, hosted on the operator's own server.

Storage and retention

Data remains in the operator's Google services and in the n8n instance. OAuth access tokens are stored encrypted on that instance and can be revoked at any time by the operator at myaccount.google.com/permissions.

Visitor data

These applications collect no data from visitors to this website. There are no forms, sign-ups, analytics or tracking cookies.

Use of Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Any changes to this policy are published on this page, with the update date revised.
